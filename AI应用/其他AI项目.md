
## 一）onyx-dot-app/onyx
https://github.com/onyx-dot-app/onyx
Onyx 是LLMs的应用层，提供了一个功能丰富的界面，任何人都可以轻松托管。Onyx 通过 RAG、网络搜索、代码执行、文件创建、深度研究等高级功能实现了LLMs。 Onyx 的核心对标是那些能帮助企业在私有环境下安全、智能地利用自身数据资产的 AI 工具。
定位对比

| 维度        | Perplexity     | Onyx                                                     |
| :-------- | :------------- | :------------------------------------------------------- |
| **一句话定位** | AI 原生搜索引擎      | 企业版 ChatGPT + 私有知识库 + AI Agent 平台                        |
| **目标用户**  | 个人用户、研究者、信息搜集者 | 企业、团队、开发者                                                |
| **数据来源**  | **互联网公开信息**    | **你公司的私有数据**（Slack、Google Drive、GitHub、Notion 等 40+ 数据源） |
| **部署方式**  | 云端 SaaS（托管服务）  | **可完全本地部署**，数据不出公司                                       |
| **开源情况**  | 闭源             | **MIT 协议开源**，可自由修改和商用                                    |
| **联网搜索**          | ✅ 核心能力，极其强大            | ✅ 支持 Web 搜索                               |
| **私有数据接入**        | ❌ 不支持                  | ✅ 40+ 数据连接器，自动同步                          |
| **RAG / 知识检索**    | ⚠️ 基础支持（搜索增强）          | ✅ 深度支持（混合搜索 + 知识图谱）                       |
| **Deep Research** | ✅ 支持（付费版）              | ✅ **开源实现**，据称排名全球第一                       |
| **代码执行**          | ❌ 不支持                  | ✅ Code Interpreter，可执行脚本                  |
| **Agent / 自动化**   | ❌ 不支持                  | ✅ 多步推理、调用工具、执行任务                          |
| **模型选择**          | 固定模型（GPT-4 / Claude 等） | **自由更换**（OpenAI / Claude / 本地模型 / Ollama） |
| **团队协作**          | ❌ 不支持                  | ✅ 团队共享、权限管理                               |
| **图像生成**          | ❌ 不支持                  | ✅ 支持                                      |
| **数据隐私** | 数据上传云端，存在外泄风险 | **Air-gapped（离线）部署**，数据完全可控 |
| **权限同步** | 不适用           | 同步原系统的文档权限（谁创建的谁可见）         |
| **定制化**  | 无法定制          | 可换模型、改检索策略、接入内部系统           |
| **定价**   | $20/月（Pro）    | **社区版免费**，企业版按需付费           |
| **数据主权** | 依赖第三方服务       | 完全自主掌控                      |
