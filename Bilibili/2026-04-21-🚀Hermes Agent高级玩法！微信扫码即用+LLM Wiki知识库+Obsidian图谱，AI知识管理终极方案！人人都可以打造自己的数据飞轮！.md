## 🏗️ LLM Wiki 三层架构

```
LLM Wiki = 3层清晰分离的知识结构
├─ 不可变层（原始资料）
├─ Agent 拥有层（Wiki 页面）
└─ 协同进化层（Schema 配置）
```

### 📦 第一层：原始来源层（不可变层）

| 特性 | 说明 |
|------|------|
| **内容** | 论文、文章、图像、数据文件、会议纪要 |
| **访问策略** | 只读不改 |
| **存储路径** | raw/ 文件夹 |
| **核心角色** | 事实的唯一源头 |
| **示例** | PDF 论文、ArXiv 链接 |

**特性**:
- 📁 原封不动保存所有资料
- 🔒 保证溯源性
- 👥 人类和 AI 都不能直接修改
- 📖 只进不出

---

### 🔄 第二层：Wiki 页面层（Agent 拥有层）

| 特性 | 说明 |
|------|------|
| **内容** | 摘要、实体概念、综述、综合分析、导航文件 |
| **文件类型** | Markdown 文件 |
| **创建更新** | 由大模型创建和更新 |
| **维护机制** | 交叉引用保持一致 |
| **示例页面** | index、concepts、entities |

**特性**:
- 📝 重新组织、消化、连接知识
- 🔗 建立反向链接
- 📊 维护知识关联网络
- 🤖 AI 自主维护

**工作流程**:
1. **完整摄入** - 大模型完整读取文档，理解全文语意
2. **知识编译** - 写入摘要页面，创建/更新实体和概念
3. **交叉引用** - 建立页面间关联
4. **编译查询** - 生成导航和总结

---

### ⚙️ 第三层：协同进化层

| 特性 | 说明 |
|------|------|
| **内容** | Schema 配置文件 |
| **作用** | 定义结构、定义约束 |
| **核心功能** | 将大模型变为纪律严明的 Wiki 维护者 |
| **演进方式** | 人类与大模型共同维护和迭代 |

**特性**:
- 📋 定义 Wiki 目录结构
- 🔧 定义新资料分类规则
- 🔗 定义链接创建规范
- 🏷️ 定义命名规范
- 📅 定义健康检查机制

## ⚖️ RAG vs Wiki 核心对比

### 传统 RAG：无状态碎片检索

```
每次查询 → 从零开始
├─ 文档分块
├─ 向量嵌入
├─ 相似度检索
├─ 临时生成
└─ 答案丢弃

特点：知识不积累、不关联
问题：重复发现相同知识
```

**核心问题**:
- ❌ 每次查询都从零开始
- ❌ 知识不积累不关联
- ❌ 问综合五篇文档的问题，必须每次都找到这五篇文档并拼凑
- ❌ 没有知识复利效应

---

### LLM Wiki：有状态知识编辑

```
完整摄入 → 知识编译 → 交叉引用 → 持续更新
├─ 完整读取文档
├─ 理解全文语意
├─ 与用户讨论要点
├─ 提取结构化知识
└─ 生成新的 Wiki 页面

特点：知识复利增长、零维护成本
```

**核心优势**:
- ✅ 完整摄入（完整理解原文）
- ✅ 知识编译（结构化整理）
- ✅ 交叉引用（建立网络）
- ✅ 持续更新（复利增长）
- ✅ 零维护成本（AI 自动承担）

## 🚀 实战演示流程

### 第一步：创建 Wiki

**命令**:
```
/llmwiki 创建一个用于存储大模型微调论文的知识库
```

**过程**:
1. 检查现有 Wiki
2. 选择新建或复用
3. 选择存储路径
4. 开始创建

**输出**:
```
✅ Wiki 创建成功
📄 写入核心文件
📚 准备好摄入论文
```

---

### 第二步：摄入论文

**支持格式**:
- 📄 PDF 文件
- 🔗 ArXiv 链接
- 📝 文档内容

**示例**:
```
摄入链接：
1. https://arxiv.org/abs/xxxx
2. https://arxiv.org/abs/yyyy
```

**AI 行为**:
- ✅ 自动提取内容
- ✅ 保存到 raw/ 文件夹
- ✅ 更新 concepts 页面
- ✅ 更新 entities 页面
- ✅ 更新 index 文件
- ✅ 与用户讨论关键要点

**提示**: 积累到 2 篇以上论文会自动建立对比页

---

### 第三步：知识研究

**命令**:
```
根据 wiki 中的论文，研究：如何防止过拟合
```

**AI 工作流程**:
1. ✅ 检查 wiki 中是否有相关页面
2. ✅ 创建新文件（如：灾难性遗忘、防止过拟合）
3. ✅ 写入详细定义和场景
4. ✅ 更新 index 和 log 文件

**成果**:
```
新增 4 个防过拟合相关页面：
- 灾难性遗忘（定义、场景、解决方案）
- 防止过拟合（定义、方法）
```

## ⚠️ 注意事项
