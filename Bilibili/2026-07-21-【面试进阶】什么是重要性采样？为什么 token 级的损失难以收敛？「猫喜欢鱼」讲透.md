## 概述

重要性采样是强化学习里绕不开的关键技术：用旧模型采的数据去训练新模型，省下反复采样的成本。但如果把它用在每个 token 上逐 token 算权重，训练反而容易不稳、难收敛。

> [!abstract] 一句话总结
> 序列的真实偏差是所有 token 权重的**乘积**，逐 token 矫正会**严重低估**该放大的程度，且单 token 波动被放大导致模型过度纠结个别 token，忽略整句合理性。

---

## 一、什么是重要性采样

### 核心思想

> [!tip] 朴素想法
> 想在一个**目标分布 P**（新策略）上算期望，但没法直接从它采样 → 退而求其次，从更容易采样的**行为分布 Q**（旧策略）取数据，再乘上**重要性权重 P/Q** 来矫正偏差。

```
目标分布 P（新策略）← 想优化但难采样
    ↑
    │ 重要性权重 = P / Q
    │
行为分布 Q（旧策略）← 容易采样，但分布不同
```

### 在强化学习中的应用

| 角色 | 对应 |
|------|------|
| **目标分布** | 想优化的新策略 π_new |
| **行为分布** | 实际用来生成数据的旧策略 π_old |
| **重要性权重** | r = π_new / π_old |

**PPO、GRPO 都是这个套路：** 先用旧策略采一批数据，更新时再用新旧策略的概率比值当权重把分布差异修正过来。这样就能拿离线数据训在线策略，不用每步都重新采样。

## 二、「猫喜欢鱼」例子：序列级 vs Token 级

### 场景设定

假设要生成"猫喜欢鱼"这三个字：

| Token | 新策略 P | 旧策略 Q |
|-------|:--------:|:--------:|
| 猫 | 0.8 | 0.5 |
| 喜欢 | 0.7 | 0.2 |
| 鱼 | 0.9 | 0.3 |

### 序列级重要性权重（真实偏差）

整句话的联合概率是各步条件概率的**乘积**：

```
P(猫喜欢鱼) = 0.8 × 0.7 × 0.9 = 0.504
Q(猫喜欢鱼) = 0.5 × 0.2 × 0.3 = 0.030

重要性权重 = 0.504 / 0.030 = 16.8
```

> [!important] 含义
> 旧策略生成这句话的概率比新策略低了 **16.8 倍**，所以要给这个样本放大 16.8 倍权重，才等效于从新策略里采样。

### Token 级重要性权重（逐 token 计算）

| Token | 权重计算 | 结果 |
|-------|---------|------|
| 猫 | 0.8 / 0.5 | **1.6** |
| 喜欢 | 0.7 / 0.2 | **3.5** |
| 鱼 | 0.9 / 0.3 | **3.0** |

验证：`1.6 × 3.5 × 3.0 = 16.8` ✓

---

## 三、Token 级重要性采样的两个坑

### 坑 1：代表性不足（严重低估）

| 维度 | 值 |
|------|-----|
| 序列真实偏差 | **16.8 倍** |
| 单个 token 权重 | 1.6、3.5、3.0（每一个都远小于 16.8） |

> [!warning] 问题
> 序列的偏差其实是这三个 token **乘起来共同造成的**。只盯着单个 token 的权重去矫正，会**严重低估该放大的程度**，矫正根本不到位。
>
> **Token 级的权重代表不了序列级的真实偏差。**

### 坑 2：方差大（训练不稳）

逐 token 算权重，会把每个 token 的波动原封不动带进训练：

```
"喜欢" 的权重 3.5 比 "猫" 的 1.6 高出一大截
    ↓
模型误以为 "喜欢" 这个 token 的偏差更需要重点关注
    ↓
使劲去调它
    ↓
可实际上这句话顺不顺，是三个字合在一起决定的
    ↓
单拎一个字出来放大是没道理的
```

> [!danger] 后果
> - 单次采样的**方差被放大**
> - 模型**过度纠结某个 token**，忽略整句合理性
> - 训练自然就**难收敛**

---

## 四、解法方向：从 Token 级抬到序列级

这也正是后来 **GSPO** 提出**序列级重要性采样**、对整句而非单 token 做裁剪的根本动机。

| 粒度 | 代表方法 | 问题 |
|------|---------|------|
| **Token 级** | PPO、GRPO | 代表性不足 + 方差大 |
| **序列级** | GSPO | 对整句做权重计算和裁剪 |

---

## 五、30 秒回顾

> [!quote] 面试要点
> 1. **重要性采样**：试用旧策略的数据估计新策略的期望，权重 = 新旧概率之比，让我们能复用离线数据
> 2. **Token 级坑 1（代表性不足）**：序列的真实偏差是所有 token 权重的乘积（如 16.8），单个 token 权重远小于它，逐 token 矫正严重低估
> 3. **Token 级坑 2（方差大）**：单 token 的波动被放大，模型过度关注个别 token 忽略整句合理性，导致难收敛
> 4. **解法方向**：把重要性采样从 token 级抬到序列级——这正是 GSPO 干的事

## 关键 Takeaways

| # | 要点 |
|---|------|
| **1** | 重要性采样 = 用旧策略数据估计新策略期望，权重 r = π_new / π_old |
| **2** | 序列级权重 = 各 token 条件概率乘积之比，反映整句真实偏差 |
| **3** | Token 级权重 = 单 token 概率之比，严重低估序列级真实偏差（乘积效应） |
| **4** | Token 级采样的两个坑：代表性不足（低估矫正）+ 方差大（单 token 波动放大） |
| **5** | 解法方向：从 token 级抬到序列级，GSPO 对整句而非单 token 做裁剪 |
