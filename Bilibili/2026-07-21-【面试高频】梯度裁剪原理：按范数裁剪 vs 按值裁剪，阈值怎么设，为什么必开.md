## 概述

某一步梯度范数突然巨大，参数被一步推飞、loss 直接变 NaN，这就是梯度爆炸。几乎所有大模型训练都默认开着梯度裁剪来避免这种事故。

> [!abstract] 一句话总结
> 给梯度长度设个上限，超了就等比缩短，**只改长度不改方向**（常取 c=1.0），配合 warmup 和小初始化，一起稳住训练。

---

## 一、梯度爆炸：几万块 GPU 白烧的元凶

### 训练的基本流程

```
算出梯度（loss 对每个参数的敏感方向）
    ↓
参数顺着梯度反方向走一小步
    ↓
loss 越来越小
```

正常情况下，梯度很温和，模型稳稳地往下走。

### 三种让梯度发飙的情况

| 原因 | 说明 |
|------|------|
| **序列特别长** | 长序列反向传播时梯度连乘放大 |
| **网络特别深** | 深层网络梯度逐层累积 |
| **学习率太大** | 步长过大导致参数更新剧烈 |

### 梯度爆炸的动画比喻

> [!abstract] 箭头比喻
> 把梯度想象成一根**箭头**：
> - **方向**：告诉参数往哪儿走
> - **长度（范数）**：决定这一步迈多大

```
正常：小箭头 → 参数小步慢走，安安稳稳
       ↓
爆炸：范数暴涨成千上万倍 → 冲出屏幕的超长箭头
       ↓
参数被狠狠推飞到毫无意义的地方
       ↓
loss 瞬间变成 NaN，训练报废
```

---

## 二、梯度裁剪的原理

### 核心思想

> [!tip] 朴素想法
> 既然箭头太长会闯祸，那就给它的长度设一个**上限（阈值 c）**。

```
测量梯度箭头总长度（范数）
    ↓
没超过阈值？──→ 一切照旧
    ↓
超过了？──→ 整根箭头等比例缩短，缩到刚好落在阈值圈上
```

> [!important] 最关键的一点
> **只缩长度，不改方向。**
>
> 参数依然朝着正确的方向走，只是这一步不再迈得那么疯。

### 两种裁剪方式对比

| 维度 | 按范数裁剪（Norm Clipping） | 按值裁剪（Value Clipping） |
|------|---------------------------|---------------------------|
| **做法** | 把整个梯度当一根箭头，整体等比缩放 | 每个分量单独砍到上限 |
| **方向** | 纹丝不动 | 被带歪了 |
| **数学** | `g' = g × (c / ||g||)` （当 `||g|| > c`） | `g'_i = clamp(g_i, -c, c)` |
| **工业实践** | **主流选择，几乎都用这个** | 很少用 |

> [!warning] 为什么不用按值裁剪
> 各分量各砍各的之后，箭头的方向就被带歪了，参数走的路都变了样。**保住方向才是关键。**

---

## 三、效果对比

### Loss 曲线

| 不做裁剪 | 开启裁剪 |
|---------|---------|
| 曲线时不时窜起一根尖刺（梯度爆炸瞬间） | 吓人的尖刺被死死摁住 |
| 运气差直接飙到 NaN，整条曲线断掉 | 曲线一路平滑地往下走 |

> [!success] 效果
> 就是这么一个小小的上限，把训练从**随时可能翻车**变成了**稳稳当当**。

---

## 四、阈值设置与最佳实践

### 阈值怎么选

| 方法 | 说明 |
|------|------|
| **经验值** | 最常用 `c = 1.0` |
| **观察法（更讲究）** | 先打印梯度范数，观察平时分布，挑一个**略高于正常水平**的值当上限 |

> 这样既拦得住暴涨，又不误伤正常的梯度。

### 配套措施

```
梯度裁剪（阈值 ~1.0）
    +
训练初期学习率预热（Warmup）
    +
更小的参数初始化
    ↓
梯度爆炸基本绝迹
```

## 三句话收口（面试标准答案）

> [!quote] 面试必背
> 1. **梯度爆炸**就是某一步梯度的范数突然暴涨，参数被推飞，loss 直接 NaN
> 2. **按范数裁剪**给梯度长度设个上限，超了就等比缩短，**只改长度，不改方向**
> 3. **阈值常取 1.0**，配合预热和小初始化更稳

## 关键 Takeaways

| # | 要点 |
|---|------|
| **1** | 梯度爆炸 = 梯度范数突然暴涨 → 参数被推飞 → loss 变 NaN |
| **2** | 按范数裁剪：整体等比缩放 `g' = g × (c / ||g||)`，只改长度不改方向，保住优化路径 |
| **3** | 按值裁剪各分量单独截断会改变方向，工业实践几乎不用 |
| **4** | 阈值经验值 1.0，更讲究的做法是观察梯度范数分布后设定 |
| **5** | 配合学习率预热 + 小初始化，梯度爆炸基本绝迹 |
