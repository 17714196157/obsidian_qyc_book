## 概述

一款免费的 Windows 桌面整理工具，一键将杂乱的桌面文件自动分类收纳到"盒子"中，同时内置动态壁纸库、状态栏透明美化、双击隐藏桌面图标、类似 Everything 的快速搜索，以及便签/日程等桌面小组件。安装简单、无广告、免费。

> [!abstract] 一句话总结
> 一键整理桌面 + 动态壁纸 + 状态栏透明 + 快速搜索 + 便签日程——免费无广告的全家桶式桌面美化方案。

## 一、核心功能一览

### 桌面文件整理

| 功能 | 说明 |
|------|------|
| **一键分类整理** | 安装后自动将桌面文件按类型归类到"盒子"中（类似桌面文件夹） |
| **自定义盒子** | 可手动创建分类盒子，如"图片"、"文档"、"视频剪辑"等 |
| **双击隐藏图标** | 双击桌面空白处可隐藏所有图标，再双击恢复 |

> [!tip] 效果
> 安装前桌面满是各种应用、文件、视频、图片、文件夹；安装后桌面整洁，所有图标自动收纳到分类盒子中。

### 壁纸美化

| 类型 | 说明 |
|------|------|
| **动态壁纸** | 内置大量动态壁纸，免费下载使用（如跑车等炫酷效果） |
| **静态壁纸** | 也支持静态高清壁纸 |
| **纯色壁纸** | 简约纯色背景可选 |

### 桌面小组件

| 组件 | 功能 |
|------|------|
| **便签** | 桌面备忘录，直接输入文字显示在桌面上 |
| **日程** | 日程提醒操作 |

### 其他功能

| 功能 | 说明 |
|------|------|
| **快速搜索** | 双击 Ctrl 键调出搜索框，类似 Everything，快速检索电脑文件 |
| **文件夹加密** | 可对电脑文件夹进行加密及调用 |
| **状态栏透明** | 自动将任务栏美化为透明效果 |
