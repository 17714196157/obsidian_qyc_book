## 简介

BN 和 LN 区别就一个字：归一化的方向。BN 跨 batch 对同一特征算，LN 对每个 token 跨特征算，Transformer 全用 LN。
共同点：都是减均值÷标准差 + γβ 缩放平移，公式 y=γ(x−μ)/√(σ²+ε)+β 一样，唯一区别是 μ、σ 沿哪个轴算。
想成立方体 batch×token×feature：BN 固定特征跨 batch 收集所有样本（竖切，依赖批次）；LN 固定 token 收集其所有特征（横切，每样本独立）。
BN 在 NLP 两硬伤：① PAD 污染——句子长短不一补 PAD，BN 同位置跨 batch 把 PAD 算进去带偏词义；② 上下文不一致——同 token 在不同 batch 和随机邻居归一化，破坏上下文一致；加上推理 batch=1 统计不可靠。
LN 对每 token 独立归一化、只用自己特征，序列长短/PAD/batch 大小通通不影响，保上下文一致、适配变长。所以从 Transformer 到所有大模型清一色 LN 及变体 RMSNorm。一句话：BN 看别人，LN 看自己。适合准备深度学习与算法岗面试的同学。
