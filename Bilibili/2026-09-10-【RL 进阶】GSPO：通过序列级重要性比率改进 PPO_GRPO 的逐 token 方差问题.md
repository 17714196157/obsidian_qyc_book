> **平均掉尖刺，更新更稳。** 一句话总结 GSPO。

---

## 1️⃣ 痛点：PPO/GRPO 的逐 token 比率方差问题

### PPO 的做法

PPO 对生成的**每个 token** 单独算一个重要性比率：

```
ρ_t = π_θ(token_t) / π_old(token_t)
```

一条 6 个 token 的回答 → 6 个比率，各算各的，有大有小。

### 两个麻烦

| 问题 | 说明 |
|------|------|
| **① 比率方差大** | 有的 token 比率接近 1，有的暴涨到 3 倍。**一个 token 暴涨，整条策略更新就被它带飞** |
| **② 逐 token 裁剪 ↔ 序列级奖励不匹配** | 裁剪粒度（token 级）和奖励粒度（序列/组级）**对不上号** |

```
Token 比率:  1.1   0.9   2.8   1.0   0.5   1.2
             ↑     ↑     ↑↑↑   ↑     ↓↓↓   ↑      ← 方差巨大
             
最终更新 ← 被 2.8 的那个 token 牵着走!
```

---

## 2️⃣ GSPO 核心公式：序列级比率

### 定义

GSPO 把整条回答的所有 token 比率压缩成一个**稳定的标量**：

```
序列比率 s = exp( (1/L) · Σₜ (log π_θ(t) − log π_old(t)) )
```

其中：
- **L** = 序列中 token 总数
- **log π_θ − log π_old** = 每个 token 的 log 比率

### 等价形式

```
s = (Πₜ ρ_t)^(1/L)
```

**几何平均（Geometric Mean）**——把所有 token 的比率求乘积，再开长度次方。

> **一句话：把一堆逐 token 的比率，平均成一个稳定的标量。**

### 为什么几何平均稳？

```
Token 比率:  2.8   0.5   1.2   0.9   1.1   1.0
             ↑↑↑   ↓↓↓   ↑     ↓     ↑     ↑

Log 空间:   +1.03  -0.69  +0.18  -0.11  +0.10  0.00
                 ↓  log 空间求均值
            均值 ≈ -0.01
                 ↓  exp
序列比率 s ≈ 0.99   ← 稳稳地贴在 1 附近！
```

暴涨（2.8）和暴跌（0.5）在 log 空间里正负抵消，**个别 token 的尖刺被平均掉，整条更新不再被它们牵着走。**

---

## 3️⃣ 裁剪升级：序列级对齐

| 对比 | PPO | GSPO |
|------|-----|------|
| **裁剪对象** | 每个 token 单独裁剪 | 只有一个序列比率 s |
| **裁剪次数** | 6 个比率里有 3 个越界 → 裁 3 次，**粒度很碎** | 最多裁 **1 次** |
| **粒度对齐** | ❌ Token 级裁剪 vs 序列级奖励 | ✅ **裁剪粒度 = 奖励粒度 = 序列级** |

> 奖励是按序列、按组来发的，比率也按序列来算——更新自然更平滑、更稳定。

---

## 4️⃣ 手算实例

```
Token 的 log 比率:  +0.6  -0.2  +0.1  -0.3  +0.2  0.0
                    └─────┴─────┴─────┴─────┴─────┘
                        sum = 0.4
                        mean = 0.4 / 6 = +0.0667
                        exp(0.0667) = s = 1.069
```

不管逐 token 的比率怎么波动，整条回答最终只用 **1.069 这一个数**来更新。

**简单、稳定、可解释。**

---

## 5️⃣ PPO vs GSPO 全景对比

| 维度 | PPO / GRPO | GSPO |
|------|-----------|------|
| 比率粒度 | 逐 token：`ρ_t = π_θ / π_old` | 序列级：`s = exp(mean(log ρ_t))` |
| 方差特性 | ❌ 方差大，极端 token 主导 | ✅ 几何平均，暴涨暴跌抵消 |
| 裁剪粒度 | 逐 token 分别裁剪 | 序列比率整体裁剪 |
| 奖励对齐 | ❌ Token 级裁剪 ↔ 序列级奖励 | ✅ 裁剪粒度 = 奖励粒度 |
| 更新稳定性 | 受个别尖刺牵制 | 平滑、稳定 |
| 可解释性 | 一堆比率，难以诊断 | 单一标量，一目了然 |

---

## 6️⃣ 与 GRPO 的关系

GSPO 可以看作 GRPO 的直接改进：

```
GRPO:   逐 token 比率 + 组内标准化优势 + K3 KL 估计
                              ↓
GSPO:   序列级几何平均比率 + 组内标准化优势 + 序列级裁剪
```

两者都保留组内标准化优势机制，GSPO 只在**比率计算方式**和**裁剪粒度**上做改进。

> 训练启动时，GSPO 的序列比率 s 同样是 1（因为 π_θ = π_old 时 log 比率全为 0），loss 稳定起步。
