问题：总结一下视频对话里的内容
来源：[[AI大模型高质量论文来源体系梳理，一条视频给你讲清楚，以后就不会乱了]]

##### 📌 主题与核心观点

视频旨在为AI学习者构建一个**系统化的高质量论文来源体系**，解决“去哪里找优质论文”的痛点。核心观点是：高质量论文主要来自**英文顶会**和**头部公司/实验室**，读者需借助AI工具（如ChatGPT）辅助阅读，打破语言障碍。

##### 🔑 关键来源体系（5大模块）

#### 1. 🏆 机器学习/深度学习三大顶会（最核心）
| 会议 | 简称 | 侧重点 |
|------|------|--------|
| NeurIPS | NIPS | 机器学习、训练、推理 |
| ICML | ICML | 机器学习、大语言模型 |
| ICLR | ICLR | 深度学习、表示学习 |

- **结论**：看到上述会议发表的论文，特别是与自身领域相关时，应重点关注。

#### 2. 🗣️ NLP/大语言模型核心会议
| 会议 | 简称 | 侧重点 |
|------|------|--------|
| ACL | ACL | 自然语言处理 |
| EMNLP | EMNLP | 自然语言处理 |
| COLM | COLM | 大模型、Agent（智能体） |

- **注**：COLM（会议）于2024年首次举办，是一个值得关注的新兴会议。

#### 3. 👁️ 计算机视觉/多模态顶会
| 会议 | 简称 | 侧重点 |
|------|------|--------|
| CVPR | CVPR | 计算机视觉、多模态 |
| ICCV | ICCV | 计算机视觉、多模态 |
| ECCV | ECCV | 计算机视觉、多模态 |

- **扩展**：这些会议还涉及具身智能、世界模型等相关论文。

#### 4. 🌐 预印本与论文检索工具
| 平台/工具 | 核心用途 | 独特优势 |
|-----------|----------|----------|
| **arXiv** | 发布最新预印本论文 | 第一时间获取最新成果（无需等待正式会议） |
| **OpenReview** | 查看论文评审与讨论 | 可看到读者评价和作者回复 |
| **ACL Anthology** | ACL系列论文数据库 | 集中收录NLP相关论文 |
| **Google Scholar** | 主流论文搜索 | 可查看引用量、引用网络，评估论文影响力 |
| **Semantic Scholar** | 类似Google Scholar | 功能重叠，但更侧重语义搜索 |
| **Hugging Face Papers** | 每日热门论文筛选 | 追踪AI热点 |

#### 5. 🏢 大模型公司/实验室（顶级学术来源）
| 公司/实验室 | 关注理由 |
|------------|----------|
| **OpenAI** | ChatGPT创造者，发布前沿研究（如GPT系列） |
| **DeepMind (Google)** | AlphaGo、Gemini大模型 |
| **Anthropic** | Claude模型，在某些方面表现更优 |
| **Meta (原Facebook)** | LLaMA系列大模型 |
| **DeepSeek (中国)** | 开源大模型，在GitHub有入口 |
| **Qwen (阿里巴巴)** | 千问大模型团队 |
| **其他中国公司** | 豆包、Kimi、智谱、讯飞、商汤等（基座大模型） |

##### 🧠 逻辑链路与重要结论

1.  **论文质量金字塔**：**顶会论文 > 公司/实验室论文 > 预印本论文**。但预印本（arXiv）是获取最新动态的首选。
2.  **语言障碍已不成问题**：借助AI工具（如ChatGPT、豆包）总结英文论文内容，可有效跨越语言壁垒。
3.  **建立个人论文来源体系**：从「顶会 → 预印本 → 公司/实验室」三个维度，构建自己的信息来源网络。
4.  **引用量是重要指标**：Google Scholar的引用量能反映论文的行业影响力，论文引用网络可帮助理解研究脉络。

##### 💡 可执行建议

1.  **建立个人论文库**：将上述会议、平台、公司网址收藏，定期浏览。例如，每周刷一次**Hugging Face Papers**和**arXiv**的AI板块。
2.  **多关注新会议**：**COLM**（2024年新办）值得重点关注，因为它可能代表更前沿的研究方向。
3.  **优先使用Hugging Face Papers**：如果你不想自己筛选，可直接用它追踪每日热点。
4.  **注意**：视频作者提到，中文高质量论文较少，因此不应只关注中文内容，而应主动拥抱英文论文，并善用AI工具。
