你有没有这种感觉 —— 剪映（CapCut）越来越贵，贵的不好用了。

以前免费的功能，现在一个一个搬到了会员里面。高级特效要钱，高级转场要钱，导出无水印也要钱。你只是想剪个视频发发抖音，结果每个月还要交一笔会员费。

剪映是个闭源软件。你剪的视频素材，上传到它的云端处理——说白了你的数据在别人服务器上过了一道。隐私方面的担心先不说，光是上传下载那点时间就够烦的。

直到我发现了这个开源项目—— **OpenCut** 。

47,000 颗 Star，MIT 协议开源，完全免费无水印，目标是成为剪映的开源替代品。

## 关于OpenCut

OpenCut 是一个 **在浏览器里跑的视频剪辑工具** 。

你没看错。不用下载客户端，打开浏览器就能剪视频。所有剪辑操作都在你的电脑本地完成，不上传服务器。导出视频也是本地直接生成， **没有水印，没有时长限制，没有付费墙** 。

项目用的是 Next.js + TypeScript 作为前端，视频处理靠 FFmpeg 引擎，运行环境是 Bun。后端用 PostgreSQL 和 Redis，整套东西用 Docker 就能跑起来。

技术栈挺现代化的，不是那种随便写个 Demo 糊弄人的东西。

## 有哪些功能

核心剪辑功能基本上都做出来了：

**多轨时间轴编辑** 。这不是那种只能剪剪拼接的玩具，支持轨道叠加，拖拽素材到时间轴上，前后修剪，精确到帧的操作。

**关键帧动画** 。可以给素材打关键帧，做位置、缩放、旋转的动画。目前还在完善中，但基本的已经能用了。

**特效和转场** 。内置了一些常用的特效和转场效果。数量没剪映那么多，但还在持续增加。

**音视频协同** 。可以调整音量包络线、做淡入淡出、控制视频播放速度。

**色彩校正** 。亮度、对比度、饱和度这些基础的调色功能是有的。

**平台预设** 。内置了抖音、TikTok、Instagram 等平台的视频参数预设，一键设置好分辨率、帧率、码率，不用自己一个个调。

**导出** 。支持 H.264 编码的 1080P 视频导出。目前最高到 1080P，4K 还没支持，不过对于绝大多数短视频创作者来说够用了。

## 要怎么安装？

有三种方式。

**第一种，在线尝鲜版（最简单）。**

去 OpenCut 的官网 opencut.app，找到在线尝鲜入口，填个申请加入候选名单。批了之后直接在浏览器里用，什么都不用装。

不过名额有限，可能要等一阵子。

**第二种，本地 Docker 部署（推荐）。**

```
git clone https://github.com/OpenCut-app/OpenCut.git
cd OpenCut
docker-compose up -d
cd apps/web
cp .env.example .env.local
```

然后安装依赖：

```
bun install
bun dev
```

打开 `http://localhost:3000` 就能用了。

这种方式最稳定，数据全在你自己电脑上。

**第三种，自己从源码构建。**

需要先装 Node.js v18+ 和 Bun。流程跟上面差不多，适合开发者。

## 跟剪映比怎么样？

直接上对比：

|  | OpenCut | 剪映 / CapCut |
| --- | --- | --- |
| **价格** | 完全免费 | 免费试用 + 付费订阅 |
| **水印** | 无水印 | 免费版有水印 |
| **隐私** | 本地处理 | 素材上传云端 |
| **开源** | MIT 协议 | 闭源 |
| **平台** | 浏览器即可 | 需下载客户端 |
| **导出** | 1080P H.264 | 支持 4K / 8K |
| **AI 功能** | 有配套 AI 工具 | 内置丰富 AI 功能 |
| **功能成熟度** | 核心功能已具备 | 非常成熟 |

OpenCut 现在的定位还不是全面替代剪映，而是"核心功能够用 + 完全免费 + 隐私友好"的组合。

如果你只是剪日常视频、发发短视频，它完全够用。如果你需要专业的 4K 调色、高级特效、AI 智能剪辑，那剪映的付费版可能还是更适合。

但你想想， **剪映也是从简单功能一步步成长起来的。** OpenCut 现在有 47k Star、90 多个贡献者在推进，迭代速度非常快。

## 说说它优点和缺点

**好的：**

完全免费。这个是最核心的优势。没有付费墙、没有功能限制、没有水印。你想导出多少次都行。

隐私好。所有处理都在本地浏览器里完成，素材不上传。对于有隐私顾虑的人来说，这一点就很值。

浏览器就能用。不需要下载几百 MB 的客户端，打开浏览器就能剪。换台电脑登录一下接着剪。

开源可定制。MIT 协议，你完全可以改源代码，加自己想要的功能。团队用的话还可以自己部署私有版本。

**不好的：**

功能还不够全。跟剪映比，特效、转场、模板的数量差距还是挺大的。4K 导出还没支持。

有使用门槛。在线版要排队，本地部署需要懂 Docker 和命令行。对非技术用户来说，不太友好。

还在快速迭代中。功能不稳定，今天能用的东西，下个版本可能就变了。Bug 也会比成熟产品多一些。

**资源占用也不低。** 在浏览器里跑视频剪辑，对电脑配置有一定要求，老电脑可能会比较卡。

OpenCut的方向是对的。 **免费、开源、本地处理、无水印导出** ——这些东西放在一起，就是很多创作者一直想要但没等到的东西。  
剪映在变得越来越强，也在变得越来越贵。OpenCut 可能永远追不上剪映的功能密度，但它也不需要追上。它只需要能满足大部分用户需要主要功能就行了，毕竟不是所有人都需要发地么丰富的剪辑功能的。
