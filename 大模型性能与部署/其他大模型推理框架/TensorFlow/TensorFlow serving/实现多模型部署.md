二）安装tfserving GPU版容器
安装仓库文档 https://github.com/NVIDIA/nvidia-docker
docker pull tensorflow/serving:latest-gpu
![[fdcbfc374ea67c591119dc78058f8900_MD5.png]]

GPU版tfserving启动命令
docker run -dt  --gpus all --name tf_serving_gpu  -p 8501:8501 -p 8500:8500  -v "/home/qyc/multiModel:/models/multiModel" -e MODEL_NAME=multiModel  tensorflow/serving:latest-gpu  --model_config_file=/models/multiModel/models.config

模型文件与配置文件：
(qqpy37) (base) ➜  multiModel ls
