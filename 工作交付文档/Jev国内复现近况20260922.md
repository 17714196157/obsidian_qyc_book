Jev 是 TypeSafe AI（前 OpenAI 研究员 Diogo Almeida 创立）2026 年 9 月 15 日发布的"System One"模型——不生成文本，只接收 state + 类型化问题（choice / score / noul），单次并行前向直接输出带校准概率的结构化决策，用 RLCD（校准决策强化学习）训练，70–500ms 延迟、输出 token 免费。它闭源、无公开权重，所以"复现"目前主要靠社区逆向 + 开源平替。

## 先说清楚：严格意义上国内还没有"官方复现"

Jev 发布至今（9 月 22 日）只有一周，国内大厂（阿里、字节、DeepSeek、智谱等）尚未发布对标产品，RLCD 的具体目标函数、训练流程也未公开，第三方对校准性的复测也还缺失。目前国内的"复现"主要是三类工作：

## 1. 架构逆向与工程解读（国内技术社区做得最多）

- 国内媒体/开发者把 Archer Hume 基于约 1 万次 API 调用的逆向工程广泛传播：Jev 本质是"共享状态前缀 + 隔离的并行问题分支 + readout head 直接读概率"的改造版 transformer，非自回归，JSON 格式化发生在应用层；confidence 字段其实是算术公式 c=(p_max−1/K)/(1−1/K)，不是学出来的。知乎、博客园、公众号上已有成体系的中文拆解（如"JEV 架构逆向：共享状态 + 并行问题分支"），这是国内复现工作的共同技术底座。
    
- 也有较冷静的技术综述指出其宣传边界："不会幻觉"只指不会生成选项外的文本，错误分类依然存在；并给出了可复现的 PoC 评估方案（Brier Score、ECE、可靠性图、置信度门禁表、Shadow→Canary 上线流程）。

## 2. 开源平替的引入、实测与再评估（国内开发者主导）
- **Laya**（Convai Innovations，Apache 2.0，非自回归 ModernBERT/mmBERT 决策引擎，choice/score/noul 三原语与 Jev 接口一致）是国内讨论和实测最多的复现对象。国内媒体做了详细报道：三个 checkpoint（421M 英文 / 322M 多语言 100+ / typed-decisions）、亚毫秒语言路由器、T4 上单问题 p50 32.8ms，自称比 Jev 快约 7.8 倍、温度校准后 ECE 0.081 vs Jev 0.246
- 国内实测文章指出了关键坑：Laya 的 0.766 准确率来自在基准训练集上微调的 checkpoint，零样本 base 模型只有 0.362（低于多数类基线 0.461），本质是"待微调的快速底座"而非开箱即用引擎；512/1024 token 的上下文远小于 Jev 的 64K；多语言版 51 种语言意图分类宏平均仅 0.227，覆盖广度≠精度。知乎上已有"Jev 开源平替 Laya 实测"和 40 条中文工单上 Jev/Laya 对比及级联方案的测试
- 还有国内团队做了 Decision Gateway Demo，用 20 条中英文合成工单同时跑关键词规则、官方 Jev、Qwen3.5-4B Scorer 和 Laya 四个后端，给出路由准确率、Brier、ECE、P50/P95 的统一对比口径。
    
## 3. 基于国产基座的复刻尝试
- **kev**（Jared Palmer 用 Devin 编写）基于 Qwen3.5 做 LoRA + pointer head 复刻 Jev 接口，镜像 System One API，官方 SDK 可直接指向本地服务，kev 训练只用交叉熵 + 温度缩放做校准，**没有复现 Jev 的 RLCD**（RL 校准决策那套），训练数据也明确声明"No Jev outputs were used for training"，所以它复现的是 Jev 的架构和 API 形态，训练目标函数是简化版。

| 模型           | 基座           | 定位                                                     |
| ------------ | ------------ | ------------------------------------------------------ |
| **Kev-0.8B** | Qwen3.5-0.8B | 轻量版，4GB 显存可微调，测试集 0.684                                |
| **Kev-4B**   | Qwen3.5-4B   | 推荐款，32GB Mac 可跑，测试集 0.837                              |
| **Kev-9B**   | Qwen3.5-9B   | 最准，测试集 0.852 / Brier 0.237，新源 dev 集 0.822 vs Jev 0.857 |
- 另有 **pngwn/system-one-qwen3.5-4b-scorer** 这类社区 checkpoint 被纳入中文评测矩阵，验证了在国产模型上复现该范式的调用链可行性
## 小结
国内目前的"复现"状态可以概括为：**解读和逆向跟得很紧（一周内就有成体系中文拆解）、开源平替的实测和批判性评估做得比国外还细（戳破了零样本能力的宣传）、但还没有国内机构自研的 RLCD 训练管线或国产 System One 模型发布**。值得盯的两个信号：一是国内团队是否会放出基于 Qwen/GLM 等国产基座、带完整 RLCD 训练代码的复现；二是 Jev 校准性在中文、长文本、分布漂移下的第三方复测数据
