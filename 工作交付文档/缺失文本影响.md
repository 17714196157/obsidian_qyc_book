主要影响的是**依赖查房记录、日常病程记录、操作/手术操作记录、其他讨论/会诊/死亡/输血/抢救等记录的接口**。纯依赖入院记录、出院记录、检查报告、病理报告、诊断文本的接口基本不受这几类缺失影响，但如果连基础字段也不传，仍可能直接返回 `3001`。

下面按字段类型梳理。

---

## 1. 依赖“查房记录”的接口

对应拼音字段大致有：  
- `cfjl`：查房记录  
- `cfjlList`：查房记录列表  
- `zfzrcfjl`：正副主任查房记录  
- `zzcfjl`：主治查房记录  
- `zdcfjl`：主刀查房记录  

受影响接口：

| 接口 | 依赖字段 | 缺失影响 |
|---|---|---|
| 21、病案首页-颅脑损伤患者入院后昏迷时间 `getPostAdmissionComaDuration` | `cfjlList` | 无法判断入院后昏迷持续时间，可能返回“不详”或证据不足 |
| 33.01、医保监管限疾病 `getSpecifiedDiseaseByLLM` | `zfzrcfjl`、`zzcfjl`、`zdcfjl` | 医保限定支付判断缺少查房证据，可能误判/漏判 |
| 33.02、医保监管限病情 `getSpecifiedDiseaseConditionByLLM` | `zfzrcfjl`、`zzcfjl`、`zdcfjl` | 同上 |
| 39、病案指控-查房记录规则判断 `zk/zhikongbyrule` | `cfjl` | 无法进行查房记录质控规则判断 |
| 41、病案生成-肝癌临床CNLC分期 `getLiverCancerCLNC` | `zfzrcfjl`、`zzcfjl` | 若分期只写在查房记录中，会抽不到，可能返回“其他” |
| 42.11、宫颈癌临床分期FIGO2018 `getCervicalCancerStagingFigo2018` | `zfzrcfjl`、`zzcfjl` | 同上，可能漏抽分期 |
| 42.12、子宫内膜癌手术病理分期FIGO2009 `getEndometrialCancerStagingFigo2009` | `zfzrcfjl`、`zzcfjl` | 同上 |
| 42.13、卵巢癌/输卵管癌/原发性腹膜癌FIGO2014 `getOvarianCancerStagingFigo2014` | `zfzrcfjl`、`zzcfjl` | 同上 |
| 43、病案生成-抽取肿瘤TNM分期 `getCancerTNM` | `zfzrcfjl`、`zzcfjl` | 若TNM只写在查房记录中，会抽不到 |

## 2. 依赖“日常病程记录”的接口

对应字段：`rcbcjl`

受影响接口：

| 接口 | 依赖字段 | 缺失影响 |
|---|---|---|
| 6、CT/MRI检查是否在病程记录中提及 `getLLMResponse` | `internal_hospital_rcbcjl` | 无法判断检查报告是否在病程记录中提及 |
| 7、使用抗菌药物的住院患者，病程记录中未记录分析 `zk/zhikongbyllm` | `internal_hospital_rcbcjl` | 无法判断抗菌药物使用是否在病程中记录分析 |
| 8、病理检查报告在医疗文本中是否记录 `getLLMResponse` | `internal_hospital_rcbcjl` | 无法判断病理诊断是否在病程记录中记录 |
| 10、接受细菌培养检查患者，病程记录未记录分析 `zk/zhikongbyllm` | `internal_hospital_rcbcjl` | 无法判断细菌培养结果是否在病程记录中记录 |
| 13、住院手术患者缺术前讨论结论 `zk/zhikongbyllm` | `internal_hospital_rcbcjl` | 如果术前讨论内容未放入该字段，则无法判断术前讨论结论 |
| 33.01、医保监管限疾病 | `rcbcjl` | 医保判断缺少日常病程证据 |
| 33.02、医保监管限病情 | `rcbcjl` | 同上 |

## 3. 依赖“操作记录 / 手术操作记录”的接口

- `yczlczjl`：有创诊疗操作记录  
- `fmjl`：分娩记录  

受影响接口：

| ----------------------------------------------------------- | ------------------------ | ---------------- |
| 33.01、医保监管限疾病                                               | `czjl`、`yczlczjl`、       | 缺少操作/证据，医保判断不完整  |
| 33.02、医保监管限病情                                               | 同上                       | 同上               |

## 4. 依赖“其他记录”的接口

图片中“其他记录”包括：疑难病例讨论、死亡病例讨论、术前讨论、术前小结、术后首次病程、交班、接班、转出、转入、阶段小结、输血、抢救、会诊等。  
文档中出现的字段大致有：

- `ynbltljl` / `ynzzjl`：疑难病例讨论记录  
- `swjl`：死亡记录  
- `sqtljl`：术前讨论记录  
- `sqxj`：术前小结  
- `sxjl`：输血记录  
- `qjjl`：抢救记录  
- `hzjl`：会诊记录  
- `fmjl`：分娩记录  
- `scbcjl`：首次病程记录  
- `24xsnryswjl`：24小时内入院死亡记录  
- `24xsnrcyjl`：24小时内入出院记录  
- `qtlxdylwb`：其他类型的医疗文本  

受影响接口：

| 接口 | 依赖字段 | 缺失影响 |
|---|---|---|
| 28、病案指控-会诊记录规则判断 `zk/zhikongbyrule` | `hzjl`、`swjl`、`ynzzjl` | 无法质控会诊记录、死亡记录、疑难病例讨论记录 |
| 40、病案指控-死亡记录规则判断 `zk/zhikongbyrule` | `swjl` | 无法质控死亡记录 |
| 13、缺术前讨论结论 | 实际需要 `sqtljl`，但接口用 `internal_hospital_rcbcjl` 承载 | 如果术前讨论记录缺失且未放入 `rcbcjl`，无法判断 |
| 33.01、医保监管限疾病 | `swjl`、`24xsnryswjl`、`24xsnrcyjl`、`ynbltljl`、`sqtljl`、`sqxj`、`sxjl`、`qjjl`、`hzjl`、`scbcjl`、`yczlczjl`、`qtlxdylwb` 等 | 医保监管判断缺少大量文书证据，容易误判 |
| 33.02、医保监管限病情 | 同上 | 同上 |
