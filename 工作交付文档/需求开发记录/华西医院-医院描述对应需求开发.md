
需求背景: 医院需要机器人编码能有 医院描述 对应上， 他们之前流程是医院描述自动关联了可选的诊断编码或者手术编码， 希望新系统依旧可以看到医院描述的对应文本描述
实现方案：
1. 我们正常过诊断手术的编码流程， 诊断用ner+不确定诊断拆分后的诊断原始语去和医院描述对应， 手术用手术编码标注语去和医院描述对应


接口麻溜：
key 就是 icd诊断或者手术名称，病案同一个编码只能有一个
value就是 医院描述，一个编码对应一个 医院描述， 医院描述 可以对应上多条编码原始语
```python
入参示例：
{
    "data_dict": {
        "icd_name": ["急性心肌梗死", "2型糖尿病伴酮症酸中毒", "高血压病III级"],
        "doc_desc":["急性心肌梗死", "2型糖尿病酮症酸中毒", "高血压3级很高危"]
    },
    "medicalRecordId": "YCSZYY5654524",
    "work": "医院描述对应"
}
出参示例：
{
  "msg": "POST request received",
  "code": 200,
  "result": {
    "急性心肌梗死": "急性心肌梗死",

  }
}
```
