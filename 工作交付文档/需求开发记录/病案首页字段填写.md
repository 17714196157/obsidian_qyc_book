
### 手术切口级别和愈合等级
#### 背景知识
手术切口等级的分类，国内目前存在**两套并行体系**，而国际上（以美国CDC为代表）则普遍采用**统一的四类法**。核心区别在于：国内病案首页用的是“0/Ⅰ/Ⅱ/Ⅲ”四类，院感监测用的是“Ⅰ/Ⅱ/Ⅲ/Ⅳ”四类，两者并非一一对应；而国外CDC体系是“Clean / Clean-Contaminated / Contaminated / Dirty”四类，与国内院感监测体系最为接近。

国内手术切口分类并非只有一套标准，不同场景下使用的分类方法不同。
**1. 病案首页分类（用于病案管理与统计）**
根据原卫生部2011年《关于修订住院病案首页的通知》，切口分为四类：

| 类别 | 定义 |
|---|---|
| **0类切口** | 体表无切口或经人体自然腔道进行的手术，以及经皮腔镜手术（如经胃腹腔镜手术） |
| **Ⅰ类切口** | 无菌切口，手术未进入感染炎症区，未进入呼吸道、消化道、泌尿生殖道及口咽部位 |
| **Ⅱ类切口** | 沾染切口，手术进入呼吸道、消化道、泌尿生殖道等，但不伴有明显污染 |
| **Ⅲ类切口** | 感染切口，包括污染切口和感染切口两种情况 |

这里需要特别注意：病案首页的“0类切口”是2011年新增的概念，专门用于微创手术的统计，这在传统外科分类中是不存在的。

**2. 院感监测分类（用于感染监测与抗菌药物管理）**
根据2010年《外科手术部位感染预防与控制技术指南》及2015年《抗菌药物临床应用指导原则》，切口同样分为四类，但编号和内涵不同：

| 类别 | 定义 | 感染风险 |
|---|---|---|
| **Ⅰ类（清洁）** | 手术不涉及炎症区，不涉及呼吸道、消化道、泌尿生殖道等与外界相通的器官 | 约1%~5% |
| **Ⅱ类（清洁-污染）** | 进入呼吸道、消化道、泌尿生殖道，但无明显污染 | 约3%~11% |
| **Ⅲ类（污染）** | 涉及急性炎症但未化脓区域、胃肠道内容物明显溢出污染、新鲜开放性创伤等 | 约10%~17% |
| **Ⅳ类（污秽-感染）** | 有失活组织的陈旧创伤、已有临床感染或脏器穿孔 | ＞27% |

**关键点**：病案首页的Ⅱ类相当于院感监测的Ⅱ类和Ⅲ类之和，病案首页的Ⅲ类相当于院感监测的Ⅳ类。临床中经常出现将这两套体系混淆的情况。

**国外的主流分类：CDC四类法**
国际上普遍采用的是美国CDC（疾病控制与预防中心）的分类体系，CDC四类法如下：

| 类别     | 英文                 | 定义                                          |
| ------ | ------------------ | ------------------------------------------- |
| **Ⅰ类** | Clean              | 未感染的切口，无炎症，未进入呼吸道、消化道、生殖道或未感染的泌尿道；必要时使用闭式引流 |
| **Ⅱ类** | Clean-Contaminated | 在可控条件下进入呼吸道、消化道、生殖道或泌尿道，无异常污染               |
| **Ⅲ类** | Contaminated       | 开放性新鲜创伤；无菌技术有明显缺陷；胃肠道内容物大量溢出；急性非化脓性炎症       |
| **Ⅳ类** | Dirty/Infected     | 有失活组织的陈旧创伤；已有临床感染或脏器穿孔                      |

**国内外核心区别对比**

| 对比维度 | 国内病案首页 | 国内院感监测 | 国外（CDC） |
|---|---|---|---|
| **类别数量** | 0、Ⅰ、Ⅱ、Ⅲ（共4类） | Ⅰ、Ⅱ、Ⅲ、Ⅳ（共4类） | Class Ⅰ~Ⅳ（共4类） |
| **有无0类** | **有**（微创/腔镜手术） | 无 | 无 |
| **清洁切口** | Ⅰ类 | Ⅰ类 | Class Ⅰ |
| **清洁-污染** | Ⅱ类（合并了院感Ⅱ+Ⅲ） | Ⅱ类 | Class Ⅱ |
| **污染** | 归入Ⅲ类 | Ⅲ类（独立） | Class Ⅲ |
| **感染/污秽** | Ⅲ类（与污染合并） | Ⅳ类 | Class Ⅳ |
| **最主要用途** | 病案统计、医保结算 | 感染监测、抗菌药物管理 | 感染监测、SSI风险预测 |

**核心差异有三点**：
**第一，病案首页与院感监测的“错位”。** 病案首页的Ⅱ类切口实际上覆盖了院感监测的Ⅱ类和Ⅲ类两个级别，这种合并是为了简化病案填写，但容易导致临床分类偏差。
**第二，0类切口是国内特有的。** 这是2011年病案首页修订时为了适应微创手术普及而增设的类别，国际上没有对应概念。
**第三，CDC体系的关注点更纯粹。** CDC分类的设计初衷是预测手术部位感染（SSI）风险，各类别的感染率有明确的循证数据支撑（Class Ⅰ约1%~5%，Class Ⅱ约3%~11%，Class Ⅲ约10%~17%，Class Ⅳ＞27%）。国内院感监测体系在定义上与CDC高度对齐，但在实际应用中，不同医疗机构对“污染”程度的判断标准可能存在差异，这也是CDC体系本身面临的一个问题——其评估者间可靠性（inter-rater reliability）并不理想。
总结来说，如果你从事的是**病案编码或医保相关工作**，需要掌握的是“0/Ⅰ/Ⅱ/Ⅲ”四类体系；如果从事的是**院感防控或手术室管理**，则应使用“Ⅰ/Ⅱ/Ⅲ/Ⅳ”四类体系，后者与国外CDC标准的可比性更强。
