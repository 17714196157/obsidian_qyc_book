## 🧠 背景：推理能力提升的困境

### 现状：RLVR / GRPO

大模型推理能力提升，现在主流靠**强化学习（RL）做后训练**，例如：

- **RLVR** / **GRPO** — 全靠**最终答案的对错**给奖励

### 核心问题：奖励太稀疏

长思维链要走到最后一步才给反馈，经常出现：
- **优势消失** — 采样出来的回答要么全对、要么全错
- 模型**根本学不到啥有效信息**

### 大家想出的解法：OPD

**OPD（Online Policy Distillation，在线策略蒸馏）：**
- 找个更强的**教师模型**
- 对学生自己生成的整条轨迹**逐 Token 打分**
- 搞出**稠密的 Token 级监督信号**

---

## 🔬 论文核心发现

### 隐藏的假设（从未被验证）

> **教师能准确评判一条根本不是它自己生成的轨迹。**

普渡大学两位作者的这篇论文，专门跑上来检验这个假设。

---

### 发现一：教师信号中大部分是噪声

**噪声定义：** 学生最后答案都错了，教师还偏偏给这条通往错误答案的 Token **打正优势**。

| 教师规模      | 监督对象    | 噪声率        |
| --------- | ------- | ---------- |
| 4B 教师     | 1.7B 学生 | **30.6%**  |
| 235B 超大教师 | 1.7B 学生 | **>50.6%** |

> **教师越大，和学生分布错位反而越严重** — 超级教师逮着学生产出的几乎所有 Token 都打负优势，根本不管内容对错。

### 发现二：学生对噪声完全不敏感

在"全是噪声的轨迹"上训练 vs "只在干净轨迹"上训练 → **最终表现几乎没差**。

> OPD 的提升，**根本就不是来自教师的专业知识**。

---

### 发现三：那 OPD 到底为什么有效？

作者做了消融实验才发现：

```
高 Logprob 的头部 Token → 几乎不提供有用梯度
所有收益集中在低 Logprob 的底部 20% 尾部 Token 上
```

而且给这些尾部 Token **啥优势**特别关键：

| 操作                   | 结果                |
| -------------------- | ----------------- |
| 给低概率 Token **正优势**   | → 策略崩溃            |
| 给低概率 Token **固定负优势** | → 复现标准 OPD 绝大部分收益 |

> **OPD 本质上就是在压制概率分布的尾部，把概率质量收拢到更可靠的路径上。**
> **这件事根本就不需要教师。**

## 🚀 OPSA：无教师的新方法

### 全称

> **On-Policy Self-Adaptation（在线策略自适应）**

### 核心思路

啥外部依赖都没有——不用教师、不用标准答案、不用外部奖励模型。

**步骤：**
1. 模型自己采样完一条回答
2. 找出 **Logprob 最低的那 20% 的 Token**
3. 给他们施加**动态负优势**
4. **惩罚强度和该位置的"困惑度"挂钩** — 困惑度越高，惩罚越强

### 公式

```
A_dyn = A_fixed - (1/4) * δ * R
```

| 参数  | 含义         |
| --- | ---------- |
| `δ` | 设为 1       |
| `R` | **归一化困惑度** |
| 效果  | 困惑度和惩罚正相关  |

> 模型完全靠自己的**内部不确定性**，就完成了自我纠偏。

## 📊 实验结果

### 数学推理基准

在 Qwen 3 / Qwen 3.5 等模型上测试：

| 基准                | OPSA 效果                                |
| ----------------- | -------------------------------------- |
| **AIME 24**       | Pass@32 从基座直接提升 **35.41 分（相对提升 263%）** |
| AIME 25 / HMMT 25 | Pass@32 **全部翻倍还多**                     |

### 与其他方法对比

| 方法       | 效果                  | 是否需要教师              |
| -------- | ------------------- | ------------------- |
| 基座       | —                   | —                   |
| 标准 OPD   | 基线                  | ✅ 需要教师              |
| **OPSA** | **比 OPD 高 16.77 分** | ❌ **不需要**           |
| GRPO     | 基线                  | 需要可验证奖励             |
| **OPSA** | **超过 GRPO**         | ❌ **不需要多次 Rollout** |

### 额外优势

- ✅ 不需要多次 Rollout
- ✅ 不需要可验证奖励
- ✅ 省掉大教师的前向传播
- ✅ **显存和时间大幅降低**
- ✅ 跨任务泛化好（代码生成 MBPP+、常识推理 GPQA 等均有提升）

## 🔍 机制分析：OPSA 到底在做什么

### 把模型转向"反思型长推理模式"

OPSA 训练后：
- 回答会**变长**
- 频繁出现 **"wait"、"but"、"however"** 等自我纠正的词（论文称之为**分叉 Token**）

### 分叉 Token 是什么

> 推理路径上的**高熵关键路口**——同时有好几个有竞争力的头部候选。

**OPSA 的做法：**
1. 压制这些路口的**低概率尾部 Token**
2. 把概率质量在**头部候选之间重新分配**
3. 帮模型更好地**闯过复杂的决策点**

### 只压尾部，不伤多样性

用 Jensen-Shannon 距离测过 OPSA 训练之后：
- ✅ 回答的**多样性和基座差不多**
- ✅ **准确率直接涨上去了**

> **两头都站住了。**

---

## 💡 核心启示

> 原来蒸馏里大家吹得神乎其神的**知识迁移**根本没那么重要。
> 真正起作用的是**对策略分布的结构性重塑**。

**OPSA** 就靠**内部不确定性**压制不可靠的路径——啥外部监督都不用，就能达到 SOTA 效果。

> 这直接给 **RL 冷启动** 和那些**找不到外部监督的领域**打开了全新的思路。
