## 一、反直觉的发现：为什么"写满卷子"不等于"考高分"？
### 1.1 传统认知的崩塌
长期以来，AI领域有一个看似合理的假设：**思维链（Chain-of-Thought, CoT）越长 = 思考越充分 = 答案越准确**。这一假设推动了o1、R1等推理模型的"长思考"竞赛——模型生成的token动辄数万，用户为昂贵的推理成本买单。
但Google团队在AIME 2024/2025、HMMT 2025、GPQA-Diamond四个高难度数学/科学基准上的测试，给出了**颠覆性结论**：

| 指标              | 与准确性的相关性             | 含义       |
| --------------- | -------------------- | -------- |
| Token长度         | **r = -0.544**（负相关！） | 越长反而越可能错 |
| 反向Token长度       | r = 0.594            | 事后调整，非因果 |
| **DTR（深度思考比率）** | **r = 0.828**        | 深度决定质量   |

![[论文解读/assets/Think-Deep,Not-Just-Long-Measuring-LLM-Reasoning-Effort-via-Deep-Thinking-Tokens/1c314fea00daa3eb7a252245f5f9369e_MD5.png]]
> **类比**：就像考试中写满卷子的人不一定分高——冗长可能意味着思路混乱、过度纠结、甚至陷入逻辑死循环。

### 1.2 "过度思考"（Overthinking）现象

论文揭示了三种"假努力"的表现：
- **冗余生成**：重复已知信息，无新推理
- **误判放大**：早期错误在后续步骤中被不断放大
- **固着偏差**：纠结无关细节，偏离核心问题
模型会陷入"自我怀疑-重新验证-再次怀疑"的螺旋。

## 二、核心创新：DTR如何"透视"模型的内心戏？

### 2.1 从"看说了多少"到"看想得多深"

Google团队的突破在于**不看表面输出，直接监听模型每一层的内部状态**。他们发现token生成存在明显分层。**图中对比了每个token中间层分布与最后一层分布的詹森香农散度】**【0(无差异)~1(明显差异)】

| -------------------------- | ---------------- | ------------------- |

| "+"、"="                    | 中层才变深            | 操作符后接内容，需一定推理       |
| "13"、"(D)"                 | 深层才变深，且首次出现后逐渐提前 | **答案标记**，需要最深层的稳定修正 |

### 2.2 DTR的数学定义
基于**关键洞察**：真正体现推理质量的，是那些**直到深层网络仍在被修正**的token——它们反映了模型在"真琢磨"而非"敷衍。 我们定义DTR指标。
**步骤1：逐层投影**
对每一层$l$的隐藏状态$h_{t,l}$，通过解嵌入矩阵$W_U$投影到词表空间：
$$p_{t,l} = \text{softmax}(W_U h_{t,l})$$
**步骤2：计算分布差异**
使用**Jensen-Shannon散度**（对称、有界）衡量中间层与最终层的差异：
$$D_{t,l} = \text{JSD}(p_{t,L} \| p_{t,l})$$
**步骤3：定义沉降深度**
$$c_t = \min\{l: \min_{j \leq l} D_{t,j} \leq g\}$$
即：JSD首次持续低于阈值$g$（通常0.5）的层数。
**步骤4：判定深度思考token**
**若$c_t \geq \lceil(1-\rho)L\rceil$（如$\rho=0.85$，即最后15%层才稳定），则标记为深度思考token。**

**步骤5：计算DTR**
$$\text{DTR}(S) = \frac{1}{T}\sum_{t=1}^T \mathbb{1}[c_t \in \mathcal{L}_{\text{deep-thinking}}]$$
> **直观理解：DTR（Deep-Thinking Ratio）= 深度思考token数 / 总token数**，" late-settling tokens"（晚沉降token）的比例。比例越高，说明模型在核心推理点上投入了更多深度计算。

![[DTR的数学定义.png]]
### 2.3 为什么选JSD？——距离度量的严谨选择
论文对比了三种距离度量（附录A）：
![[三种距离度量（附录A）.png]]

| 度量                   | AIME 25相关性  | HMMT 25相关性  | 问题                |
| -------------------- | ----------- | ----------- | ----------------- |
| **Jensen-Shannon散度** | **r=0.869** | **r=0.895** | ✅ 对称、有界、稳定        |
| KL散度                 | r=-0.698    | r=0.409     | ❌ 非对称，早期高熵导致数值不稳定 |
| 余弦相似度                | r=0.633     | r=0.172     | ❌ 不稳定，相关性弱        |

**关键原因**：早期层的预测往往是高熵且平坦的，KL散度会因概率质量分散而人为变小，导致误判。JSD的对称性避免了这一问题。

## 三、实证验证：DTR的跨模型稳健性
**实验逻辑思路：** 哪些推理时的信号能有效预测模型回答的正确性？--- 测试了7种不同的推理时度量指标，看它们与最终任务准确率的相关性（Pearson correlation）
```
问题：如何不依赖ground truth，在推理时判断答案是否正确？
    ↓
基线：测试6种常见指标（长度类、置信度类）
    ↓
发现：现有指标在不同模型/任务上表现极不稳定（符号翻转、相关性波动）
    ↓
解决：提出 DTR 方法
    ↓
验证：在8模型×4基准=32个配置中，DTR保持最稳定的强正相关
    ↓
结论：DTR是更可靠的"推理难度/正确性"预测指标
```

**实验发现**：

| 指标                   | 平均相关性      | 解读                              |
| -------------------- | ---------- | ------------------------------- |
| Token Length         | **-0.594** | 强负相关：答案越长反而越可能错？                |
| Reverse Token Length | **0.594**  | 强正相关：短答案更可能正确                   |

### 3.3 深层逻辑：为什么传统指标会失效？
| 现象                 | 解释                                |
| ------------------ | --------------------------------- |
| Token Length 符号不一致 | 不同任务的最优推理长度不同：数学题需要长思维链，常识题过长反而啰嗦 |
| Log Prob 在强模型上失效   | 强模型对所有答案都过度自信，概率区分度低              |
| Self-Certainty 表现好 | 可能捕捉了某种"内部一致性"                    |
| **DTR 更稳健**        | 可能结合了长度和置信度的优势，或采用了某种归一化/相对化策略    |

### 3.4 超参数敏感性分析---沉降阈值与深度分数的影响
DTR的计算依赖两个超参数：
- 沉降阈值 g ：JSD距离低于此值视为"稳定"
- 深度分数 ρ ：定义"深层"的边界（如0.85表示最后15%层）
**探讨问题：这些参数的选择是否会影响DTR与准确性的相关性？是否存在稳健的配置？**

图4展示了$g$（沉降阈值）和$\rho$（深度分数）的影响，实验设计（控制变量法）：
![[论文解读/assets/Think-Deep,Not-Just-Long-Measuring-LLM-Reasoning-Effort-via-Deep-Thinking-Tokens/047b95d3c0f77a7e0cc99e184c9afd0c_MD5.png]]

| 子实验 | 固定参数        | 变化参数                                | 目的          |
| --- | ----------- | ----------------------------------- | ----------- |
| 图4a | $\rho=0.85$ | $g \in \{0.25, 0.5, 0.75\}$         | 测试阈值严格程度的影响 |
| 图4b | $g=0.5$     | $\rho \in \{0.8, 0.85, 0.9, 0.95\}$ | 测试深度定义范围的影响 |
**发现1：严格标准降低DTR绝对值，但不破坏正相关趋势**
> "施加更严格的标准——更高的稳定阈值$g$或更低的深度比例$\rho$——会导致平均晚期稳定令牌比率的下降"

**机制解释**（因果链）：
```
更高的g → 要求中间状态更接近最终输出才算"稳定" → 更晚才被判定为稳定
更低的ρ → "深层"范围更窄（如从最后20%缩到10%） → 更少token满足条件
→ 两者都过滤掉更多候选 → DTR数值降低，但保留下来的都是"真深度思考"
```
**发现2：$g$的选择比$\rho$更关键**

| 配置 | AIME 25相关性 | 问题 |
|------|------------|------|
| $g=0.25$（过松） | $r=0.820$ | 包含"假深度"token，趋势平缓 |
| $g=0.5$（推荐） | $r=0.962$ | **最佳平衡点** |
| $g=0.75$（过严） | $r=0.012$ | 过滤掉有价值token，不稳定 |

**关键洞察**：$g=0.5$是"甜点"——既足够严格以排除噪声，又不至于过滤掉信息性计算。

**发现3：$\rho$对相关性影响较小，主要影响动态范围**
图4b显示所有$\rho$配置都保持正斜率，说明：
- DTR指标对"深层"的具体定义**相对稳健**
- $\rho$主要调整的是DTR的**数值范围**，而非**预测能力**
**最终推荐**：$(g, \rho) = (0.5, 0.85)$

## 五、深层机制：为什么"高推理级别"反而DTR更低？
图7展示了GPT-OSS-120B模型在不同推理级别配置（即低、中、高）下DTR的变化情况。我们在AIME 25和GPQA-D数据集上观察到一个有趣且一致的趋势：尽管底层模型权重完全相同且仅系统提示存在差异，但较低推理级别的配置表现出更高的DTR值，而较高推理级别的配置则系统性地产生更小的DTR，同时实现更好的任务准确率。
![[附录B的图7.png]]
附录B的图7揭示了一个有趣现象：

| 推理级别 | DTR范围 | 准确率 | 解释 |
|---------|--------|--------|------|
| Low | 较高 | 较低 | 每个token需深层修正，但序列短 |
| Medium | 中等 | 中等 | 平衡深度与长度 |
| High | **较低** | **较高** | 计算重新分配：深度↓，长度↑，总计算↑ |

**机制解释**：高推理级别模型将计算从"每个token的深度"转移到"生成更多token"——扁平化逐层计算，增加前向传递次数，总计算量更大，但DTR作为**比例指标**反而降低。

> **启示**：DTR是**序列归一化**指标，跨模型比较需谨慎；但在**同一模型/同一配置内**，DTR是可靠的质量预测器。

## 相关基础知识补充说明
##### 詹森香农散度
詹森香农散度（Jensen-Shannon Divergence, JSD）是衡量两个概率分布之间差异的常用指标，它是**Kullback-Leibler散度（KL散度）**的对称且平滑版本。
给定两个概率分布 $P$ 和 $Q$，JSD 定义为：
$$JSD(P \parallel Q) = \frac{1}{2} D_{KL}(P \parallel M) + \frac{1}{2} D_{KL}(Q \parallel M)$$
其中：
- $M = \frac{1}{2}(P + Q)$ 是**平均分布**
- $D_{KL}$ 是 KL 散度

| 特性 | 说明 |
|------|------|
| **对称性** | $JSD(P \parallel Q) = JSD(Q \parallel P)$ |
| **有界性** | $0 \leq JSD(P \parallel Q) \leq \ln(2)$（使用以2为底的对数时为 $[0,1]$）|
| **平滑性** | 即使 $P$ 和 $Q$ 的支撑集不相交，JSD 仍然有限 |
| **度量性质** | $\sqrt{JSD}$ 满足三角不等式，是真实度量 |

与 KL 散度的对比

| | KL 散度 | JSD |
|--|---------|-----|
| 对称性 | ❌ 不对称 | ✅ 对称 |
| 有界性 | ❌ 可能为 $+\infty$ | ✅ 有上界 |
| 平滑性 | ❌ 要求支撑集包含 | ✅ 始终有限 |
| 计算 | 直接计算 | 需计算平均分布 $M$ |

```python
import numpy as np
from scipy.spatial.distance import jensenshannon
from scipy.special import kl_div

def js_divergence(p, q):
    """计算詹森香农散度"""
    p = np.asarray(p)
    q = np.asarray(q)
    # 归一化
    p = p / p.sum()
    q = q / q.sum()
    m = 0.5 * (p + q)
    # JSD = 0.5 * KL(P||M) + 0.5 * KL(Q||M)
    return 0.5 * np.sum(kl_div(p, m)) + 0.5 * np.sum(kl_div(q, m))

# 使用 scipy（返回的是距离，即 sqrt(JSD)）
p = [0.1, 0.2, 0.3, 0.4]
q = [0.4, 0.3, 0.2, 0.1]
js_distance = jensenshannon(p, q)  # 这是 sqrt(JSD)
js_div = js_distance ** 2  # 这才是 JSD
```
JSD 可以看作：**两个分布各自到"中间地带"的平均距离**。这种设计既保留了信息论的解释，又克服了 KL 散度的非对称性和无界性问题，使其成为实际应用中更稳健的选择。
