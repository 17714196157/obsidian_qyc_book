
一、Skill 里面到底有什么？
1. 文件组成
类型	文件	说明	
必须有的文件	`skill.md`	Skill 的核心文件，Markdown 格式	
可选的文件	`references/`	参考文献/知识库	
	`scripts/`	脚本文件（代码）	
	`assets/`	资源/资产，项目所需的静态资源（如图片、样式表等）	
---

二、核心文件：skill.md 的结构
```
┌─────────────────────────┐
│  name: 名字              │  ⎫
│  description: 描述 ⭐   │  ⎬  名片（Header）
│  ─────────────          │  ⎭
│  步骤...                │
│  规则...                │  ⎫
│  输出要求...            │  ⎬  Body（正文）
│  ...                    │  ⎭
└─────────────────────────┘
```

2.1 名片部分（Header）

字段	作用	
`name`	Skill 的名字	
`description`	描述（重点 ⭐）	

2.2 一个好的描述至少要清楚两件事：
1. 这个 skill 是做什么的
2. 什么时候应该使用它

2.3 正文部分（Body）
- 步骤
- 规则
- 输出要求
- 其他执行细节...

---

三、三个可选文件夹的用途

文件夹	解决什么问题	具体内容	
`references/`	查什么资料	知识、文献（如：品牌规范、合规手册、政策等）	
`scripts/`	运行什么代码	成品代码、脚本（如：生成表格的脚本）	
`assets/`	使用什么素材	静态素材（如：Logo、图片等）	

---

四、核心总结

文件/文件夹	核心作用	
`skill.md`	解决 是否做 和 怎么做	
`references/`	解决 查什么资料	
`scripts/`	解决 运行什么代码	
`assets/`	解决 使用什么素材	

> 💡 本质：这 4 个文件共同决定 —— AI 能不能在正确的时候，做正确的事

---

五、Skill 调用关系示意图

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────────────────────────┐
│ Skill 1 │    │ Skill 2 │───→│ Skill 3 │───→│ Skill 3 仓库                 │
│ 技能1   │    │ 技能2   │    │ 技能3 ⭐ │    │ ┌─────────┬─────────┬─────┐ │
│         │    │         │    │         │    │ │refrences│ scripts │assets│ │
│skill.md │    │skill.md │    │skill.md │    │ │ (知识)  │ (代码)  │(素材)│ │
└─────────┘    └─────────┘    └─────────┘    │ └─────────┴─────────┴─────┘ │
                                              └─────────────────────────────┘
                                                    ↓         ↓         ↓
                                                  知识文献   成品代码   静态素材
                                                  规范手册   脚本      Logo/图片
                                                  政策等     生成表格等
```

调用逻辑
- AI 根据任务判断 → 选择合适的 Skill → 读取 `skill.md` 决定执行策略
- 如需扩展能力 → 调用 `references` / `scripts` / `assets`

---

六、关键要点
1. `skill.md` 是核心 —— 必须存在，决定 Skill 的"大脑"
2. 描述（description）至关重要 —— 直接影响 AI 何时调用该 Skill
3. 三个可选文件夹按需配置 —— 不是所有 Skill 都需要代码或素材
4. 最终目标 —— 让 AI 在正确的时候，用正确的方式，做正确的事
