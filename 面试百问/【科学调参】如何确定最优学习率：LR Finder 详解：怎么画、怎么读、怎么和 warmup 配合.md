## 📺 视频简介

学习率设多少？0.1 太大、0.001 太小、0.01 可能行——**别猜了**，用 Learning Rate Finder 一眼看到最优区间。

适合做大模型训练调参 & 准备训练岗面试的同学。

---

## 🧠 原理：LR Finder 怎么工作

从一个**极小的学习率**开始（如 1e-7），每个 batch **线性增大**学习率，同时记录 loss，画出 **loss 随学习率变化的曲线**。

> 曲线会经历三个阶段：

```mermaid
graph LR
    A[学习率极小] -->|loss 平稳微降| B[学习率适中]
    B -->|loss 急剧下降 ✅| C[学习率过大]
    C -->|loss 反弹上升 ❌| D[训练发散]
```

| 阶段 | 学习率 | Loss 表现 | 含义 |
|------|--------|-----------|------|
| ① 左端 | 太小 | 平稳微降 | 模型几乎不学 |
| ② 中间 ✅ | **刚好** | **急剧下降** | **模型快速学习 → 合适区间** |
| ③ 右端 | 太大 | 反弹上升 | 训练发散 |

---

## 📖 怎么读曲线

### 最优学习率的取法

**不是取 loss 最低点，而是取急剧下降区域的中间偏左。**

> 通常是 loss 下降**最陡的点 ÷ 10**。

**经验值举例：** 如果曲线在 `1e-3 ~ 1e-2` 之间急剧下降，取 **3e-4** 作为起点。

```
最陡下降点 = 1e-2
         ↓ ÷ 10
实际起点 = 1e-3
         ↓
推荐值   ≈ 3e-4  (中间偏左)
```

## 🛠️ 实操步骤

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① | 选工具 | PyTorch `lr_finder` / fastai `lr_find` |
| ② | 设范围 | 起始学习率 `1e-7`，结束学习率 `1e1` |
| ③ | 跑样本 | **100 ~ 200 个 batch** |
| ④ | 画曲线 | `loss vs lr` |
| ⑤ | 找最陡点 | 找到 loss 下降最陡的点 |
| ⑥ | 除以十 | 最陡点对应的 LR ÷ 10 = 实际初始 LR |

---

## ⚠️ 注意事项

| # | 注意点 | 说明 |
|---|--------|------|
| 1️⃣ | **曲线很嘈杂** | 需要用**移动平均**做平滑处理 |
| 2️⃣ | **Batch size 变了要重跑** | 不同 batch size 对应不同的最优 LR |
| 3️⃣ | **Warmup 会影响结果** | 建议 **LR Finder 不加 warmup** 跑 |
| 4️⃣ | **只告诉你初始 LR** | 后续的衰减策略要另外选 |

## 🔄 LR Finder 与 Warmup 的关系

LR Finder 找到的最优学习率通常**偏大**，需要配合 warmup 使用：

```
                  ▲ LR
                  │
     LR Finder   │    ╱╲
     峰值 ───────│───╱──╲──────────
                  │  ╱    ╲
                  │ ╱      ╲
                  │╱        ╲
                  │          └──→ cosine decay 到接近零
                  │
                  └──────────────────────► 步数
                  ↑
               warmup
           (0 → 峰值, 线性增长)
```

**实操建议：**
- Warmup 从零**线性增长**到 LR Finder 找到的峰值
- 然后进入 **Cosine Decay** 到接近零
- Warmup 步数 ≈ **占总步数的 1% ~ 2%**

> 这样既利用了 LR Finder 的结果，又避免了训练初期学习率太大导致不稳定。

## 📋 30 秒回顾

1. **LR Finder 做法**：从很小的学习率一路往上扫，同时记录 loss 画成曲线
2. **曲线三段**：平稳 → 急降 ✅ → 反弹 ❌
3. **最优 LR**：取在最低点**左侧一个量级**的位置，而不是最低点本身
4. **实际使用**：配上 **warmup**（1~2% 步数） + **cosine decay**，峰值由 Finder 来定

> **一句话带走：学习率不用猜，扫一遍曲线，它自己会告诉你。**
